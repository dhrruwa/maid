# Mobbin references

Layout, spacing and interaction patterns were taken from these screens. No branding, logos or exact visuals were copied.

## Owner app – "Owner"

| Screen | Reference picked | Why / what we took |
|---|---|---|
| PIN lock | [Jomo – Create a passcode](https://mobbin.com/screens/46153052-2d7f-41cc-801d-cd64e37378db), [Klarna – Confirm your PIN](https://mobbin.com/screens/a0f17c45-6dc6-4714-aa28-18cbe1b80d45) | Four dots + large round keypad, title and one-line helper at the top. "Create → Confirm" two-step from Klarna. |
| Onboarding / setup steps | [Opera – Connect](https://mobbin.com/screens/311067b8-4d20-412a-bfab-1146a9d72d7e) | One illustration/icon, one sentence, one primary button per step. We use a stepper (1 PIN, 2 Location, 3 House QR, 4 Pair). |
| Dashboard | [Lloyds – My net worth](https://mobbin.com/screens/fd0be564-d70d-4755-af2c-84f6ade7b032), [Cash App – Earnings card](https://mobbin.com/screens/742da727-0bf2-4ae6-9722-1cf412aadfad) | Big bold total at the top of a soft card, a thin progress bar, then a legend/breakdown with dots. Stacked rounded cards below. |
| Calendar | [Noom – streak calendar](https://mobbin.com/screens/5c506133-1cc8-470f-b791-468980acda12), [MacroFactor – Weigh-in](https://mobbin.com/screens/20a1a56c-579e-43be-acc1-56ef497595b9) | Filled circles per day for status, month header with arrows, legend row under the grid. |
| Day details | [Stardust – day card](https://mobbin.com/screens/5b574bc6-21bb-4c11-9914-d5bcc0fcd4c9) | Tapping a day opens a bottom sheet with the date as the title and details below. |
| QR display / pairing | [Perplexity – 2FA setup](https://mobbin.com/screens/cc1610d7-b05d-4709-bfd6-fda78717527b), [Comet – Add device](https://mobbin.com/screens/3670b77f-56c3-49f6-bd8c-4befe2a80b1f) | Instruction text, large QR in a white rounded tile, and a manual code shown below as a backup. |
| Menu planner | [MacroFactor – Recipes library](https://mobbin.com/screens/c7e43af3-f255-4280-871f-5f9da6d2ff53), [Lifesum – Add to recipe](https://mobbin.com/screens/57072cd0-febd-4ea1-97f1-4850243a1cab) | List rows with a trailing "+" to add from saved dishes; segmented control (Morning / Evening). |
| Leave requests | [Stardust – Follow requests](https://mobbin.com/screens/a00b9d8d-ecb3-49e7-8d1c-fb583ec3486f) | Request row with inline action buttons on the right; we expand to Paid / Unpaid / Reject. |
| Holidays | [CLEAR – Add a flight date picker](https://mobbin.com/screens/b5227913-303b-44b9-88f5-b8dd43c5007e) | Bottom sheet with quick chips (Today / Tomorrow) above a date range, one primary button at the bottom. |
| Activity history | [LinkedIn – Notifications with filter chips](https://mobbin.com/screens/2f976b2e-5bd9-4b99-ab34-12988fd7d200), [Fresha – Activity](https://mobbin.com/screens/30808d0c-ebc8-46b5-91af-6bf7d456f01e) | Horizontal filter chips above a newest-first feed; each row has an icon, sentence and time. |
| Payment slip | [Fresha – Invoice](https://mobbin.com/screens/67f765ef-c59f-478c-98d0-a46a3b103a1f), [Shop – Receipt](https://mobbin.com/screens/9abcfbfe-666f-4d55-8235-20900f8c4a7b) | Header block (who/when), line items, bold total, then two buttons: Share / Download. |
| Settings | [Perplexity – Notifications](https://mobbin.com/screens/2529b4b9-86d6-406f-b9d8-f3271208cfcd) | Grouped rounded card, icon + title + one-line description + switch per row. |
